### 결정/가정 메모
- **포장(takeout)** 의 경우 배달 주소·배달기사 요청사항이 의미가 없으므로 **주소 입력 면제, 배달비 0원** 으로 처리(연락처는 필수 유지). — 추후 변경 가능.
- **리뷰**: 로그인한 손님이면 식당당 작성 가능(주문 이력 강제는 하지 않음, MVP). 별점 1~5 + 내용.
- **옵션 변경**: 사장님이 옵션을 정의하는 구조 대신, 손님이 항목별로 자유 텍스트(옵션/요청)를 입력·수정하는 방식(MVP).
- **비밀번호 규칙**: 길이 8자 이상 + 영문 대문자 + 영문 소문자 + 특수문자. (숫자는 명시 요구 없어 필수 아님)

### 2차 결정 / 가정 메모
- **요청사항**: 1차(CR-11)에서 "필수"였으나 2차 요청으로 **선택**으로 변경. 주소·연락처는 여전히 필수, 연락처 형식 검증 유지.
- **배달지역(CR-19)**: 가게마다 배달 가능한 **동 목록**을 등록(사장님 입력 / 시드). 홈에서 동을 고르면 그 동에 배달되는 가게만 노출. 동 미선택(전체)이면 전체 표시.
- **리뷰 권한(CR-12)**: 그 식당에서 **주문 이력이 있는 로그인 사용자**만 작성 가능.
